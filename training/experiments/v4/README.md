# YOLOv8-seg v4 실험

## 1. 실험 목적
기존 v3 모델의 실제 촬영 이미지 탐지 성능을 개선하기 위해 AI Hub 데이터를 추가한 v4 데이터셋으로 학습을 진행하였다.

## 2. 학습 방법
- 모델: YOLOv8n-seg
- 데이터셋: tactile_blocks_v4
- 클래스: linear(선형), dot(점형)
- 학습 방식: 사전학습된 YOLOv8n-seg 가중치에서 새로 학습(v4_fresh)

## 3. 평가 결과

| 지표 | v3 | v4_fresh |
|---|---:|---:|
| Mask Precision | 0.9088 | 0.9553 |
| Mask Recall | 0.9019 | 0.8921 |
| Mask mAP50 | 0.9113 | 0.9166 |
| Mask mAP50-95 | 0.8303 | 0.8285 |
| Linear mAP50-95 | 0.7661 | 0.7614 |
| Dot mAP50-95 | 0.8944 | 0.8956 |

## 4. 실사진 비교 결과
v4_fresh는 일부 점형 블록 탐지 신뢰도가 개선되었지만, 나무와 건물 등 배경을 점자블록으로 잘못 탐지하는 문제가 확인되었다.

v3와 v4_fresh 모두 일부 야간 사진에서 점자블록을 탐지하지 못했다.

## 5. 결론
두 모델의 정량 평가 성능은 비슷하며, 실사진에서는 각각 오탐과 미탐 문제가 존재한다.

현재 서비스 개발에서는 v3를 기준 모델로 유지하고, 향후 배경 데이터 및 다양한 촬영 환경을 추가하여 개선할 예정이다.
